# Contributing

Thanks for contributing.

## Setup

```bash
npm ci
cp WORKFLOW.example.md WORKFLOW.md
```

Set `LINEAR_API_KEY` in your shell before running intake paths.

## Validation

- `npm test`
- `npm run build`
- `npm run artifacts:public` when touching public screenshots

## Pull Requests

- keep PRs focused and small
- include a short behavior summary
- include verification commands used
- update docs when behavior or workflow contracts change
