# Public Manifest

This repository is intended for public GitHub publication.

## Included

- source code under `src/`
- public docs under `docs/`
- sanitized screenshots under `artifacts/public-release/`
- architecture and workflow examples

## Excluded

- local environment files (`.env`, private config variants)
- live workspace identifiers or tracker internals
- local logs, caches, and temporary runtime artifacts

## Fork Attribution

This repo is a fork-oriented extension of Symphony workflow patterns. Upstream model authorship is not claimed here; the contribution focus is the planning and projection layer.
